# 🚀 PagePulse – Website SEO & Health Audit Tool

Built for the **Digital Heroes Software Development Internship Task (Task A & Task B)**.

## 📌 Project Overview

PagePulse is a modern web-based SEO and website health auditing tool that analyzes any website URL and generates a clean report containing essential SEO and technical information.

The goal of this project is to help developers, marketers, and website owners quickly inspect the basic health of a webpage without using complex SEO software.

## ✨ Features

- Analyze any website URL
- HTTP Status Code
- Response Time
- Page Title Detection
- Meta Description Detection
- H1 Tag Count
- Approximate Word Count
- Missing Image ALT Tags
- Modern Responsive Dashboard
- Export Report as JSON
- Export Report as PDF
- Clean Dark UI
- Mobile Friendly Design

## 📖 How to Use

1. Open the website.
2. Paste a valid URL (Example: https://openai.com).
3. Click **Analyze Website**.
4. Wait for the audit.
5. Review the generated SEO report.

---

## 🧠 Design Decisions

### 1. Single Page Layout

I designed the application as a single-page interface so users can complete an SEO audit without navigating between multiple pages.

---

### 2. Dark Modern UI

A dark theme was selected to improve readability while giving the application a professional appearance.

---

### 3. Simple Audit Dashboard

Instead of overwhelming users with technical data, the dashboard presents only the most important SEO metrics clearly.
