PagePulse – SEO & Website Health Audit Tool
Overview

PagePulse is a modern web application that analyzes websites and provides an easy-to-understand SEO and website health report.

It was built as part of the Digital Heroes Internship Qualification Task.

Analyze any website URL
Overall Website Health Score
HTTP Status Check
Response Time Analysis
